Original application source was authored for this project. No license for the user's original application code is added here. Upstream dependencies and data retain their own licenses; their notices must be retained when redistributing this package.

## Geographic metadata

Country data: https://github.com/mledoze/countries, npm world-countries 5.1.0, Open Database License (ODbL). Generated database: `lib/countries.json`. License: `public/licenses/countries-ODbL.txt`. This derived database is provided under the same ODbL terms. Generated by `scripts/prepare-data.mjs`; transformed fields and assigned continent labels are documented there.

Map geometry: https://github.com/topojson/world-atlas, world-atlas 2.0.2, ISC. Underlying Natural Earth data is public domain. License: `public/licenses/world-atlas-ISC.txt`. `public/data/world.json` is an unmodified countries-50m.json copy.

Region/city data: https://github.com/harpreetkhalsagtbit/country-state-city, version 3.2.1, GPL-3.0. Derived database files under `public/data/regions/` retain GPL-3.0. License: `public/licenses/country-state-city-GPL-3.0.txt`. The corresponding source database is available in the pinned package and can be obtained by `npm ci`; the included generation script reproduces our simplified country files (state code/name; city name/state). These plaintext files are already the preferred editable form for the simplified data. Preserve the applicable source and license terms when redistributing.
